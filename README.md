## Настройка подключения к базе данных

Перед запуском необходимо задать переменные окружения:

DB_URL=jdbc:mysql://localhost:3306/animals_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
DB_USER=root
DB_PASSWORD=пароль_локального_пользователя

Пароль не хранится в исходном коде и не добавляется в Git.
